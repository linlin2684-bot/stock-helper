股票小幫手 — 檔案說明

index.html 等檔案　　App 本體
scripts/build_data.py　每天自動抓股價、法人買賣、本益比、營收、除權息，算好選股指標
.github/workflows/　　 讓 GitHub 每個交易日自動執行上面的程式，並把 App 發布成網站

上線方式：連結 GitHub 帳號後，由 Claude 幫你建立專案並發布，
網址會是 https://你的帳號.github.io/stock-helper/

自動更新時間（台灣時間）：
- 週一到週五 17:20：更新台股（收盤、法人買賣公布之後）
- 週二到週六 05:40：更新美股（美股收盤之後）

注意：
- 自選股、持股和模擬帳戶存在各自的手機裡，換手機前請到「設定 → 匯出備份」。
- 股價是每天收盤後更新，不是即時報價。
- 分析、預測與回測僅供參考，不構成投資建議。
